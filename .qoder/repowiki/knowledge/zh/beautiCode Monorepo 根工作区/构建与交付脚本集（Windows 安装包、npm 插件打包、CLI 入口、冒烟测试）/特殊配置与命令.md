`npm run plugin:pack` / `plugin:publish` 触发 `pack-dsh-plugin.mjs` 产出 `artifacts/dsh-plugin/`；`npm run installer:windows` 调用 `build-windows-installer.ps1` 需 Windows 环境且已安装 Inno Setup 6；`npm run smoke:live` 运行 `live-smoke.mjs --port <cdpPort>` 要求本机有可探测的 Codex CDP；`npm test` 在各包内通过 `node scripts/test-runner.mjs node --test ...` 执行以规避 Windows 短路径导致的 flaky 问题。
