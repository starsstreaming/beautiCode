根级统一命令：`npm run build` 顺序构建三个包；`npm run test` / `npm run typecheck` 分别遍历三个包；`npm run discover` 与 `npm run bc` 走 scripts/beauticode.mjs CLI；`npm run smoke:live` 先构建再运行真实浏览器冒烟测试；`npm run tray` 启动托盘；`npm run installer:windows` 生成 artifacts/windows/installer 下的安装包；`npm run plugin:pack` / `plugin:publish` 打包并发布 beauticode-dsh npm 插件。
