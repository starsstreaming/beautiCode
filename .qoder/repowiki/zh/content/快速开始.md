## 简介
beautiCode 是一个本地背景工具，主要为 DeepSeek Harness 和 Codex Desktop 提供图片、视频等背景能力。它不会把工作窗口变成播放器，而是让媒体安静地待在对话和工作区后面，不影响代码输入框与按钮的正常使用。

## 环境要求与安装方式总览
- Node.js 版本要求：Node.js 22 或更高版本（源码开发与部分脚本需要）。
- 支持平台：Windows；主要宿主为 DeepSeek Harness（推荐），也支持 Codex Desktop。
- 支持的媒体格式：JPG、JPEG、PNG、WebP 图片；MP4 视频。

三种安装路径：
- 仅给 DeepSeek Harness 加背景：使用一键命令安装插件，无需源码与安装包。
- Windows 安装包：适合需要系统托盘、自动写入 DSH 插件、或不想维护源码的用户。
- 从源码运行：适合开发者或希望完全自定义集成流程的用户。

## 一键安装插件：npx beauticode-dsh
这是最快捷的方式，只需一条命令即可为 DeepSeek Harness 添加背景能力。

操作步骤
1. 确保已安装并运行 DeepSeek Harness（先自行安装 DSH 并运行 dsh web）。
2. 在终端执行：
   - npx beauticode-dsh
3. 打开网页后，侧栏“设置”上方会出现“背景”。你可以：
   - 从文件夹选择图片或 MP4
   - 清除背景
   - 开关声音
   - 切换已保存主题
4. 也可以使用斜杠命令 /bg、/bg-theme、/bg-clear，或直接跟 AI 说把本机图片/视频设为背景。
5. 卸载插件：
   - npx beauticode-dsh --remove

说明
- 该命令会从 npm 下载插件并写入你的 DSH profile，不需要 pnpm，也不需要再执行 dsh plugin add。
- 如果已将 dsh 加入 PATH，第二行也可以写成 dsh web。
- 已有 pnpm 时，也可以通过 DSH 的命令安装：
  - npx @deepseek-ai/dsh plugin --profile web add beauticode-dsh
  - npx @deepseek-ai/dsh web

## Windows 安装包安装
如果你需要系统托盘、自动写入 DSH 插件，或者不想维护源码，可以下载 Windows 安装包。

安装步骤
1. 下载最新安装包。
2. 运行安装包，默认安装到用户目录下的 Programs\beautiCode。
3. 安装完成后，自行启动 DeepSeek Harness：
   - dsh web
   - 未把 dsh 加入 PATH 时：npx @deepseek-ai/dsh web
4. 打开网页后，侧栏“背景”即可使用。
5. 如果需要 Codex Desktop，仍要开启 beautiCode 托盘：
   - 选 Codex Desktop：按需拉起 Codex
   - 选 DeepSeek Harness：只连接你已经启动的 DSH 网页，不会替你启动 DSH

注意事项
- 安装包自带 Node.js，不需要另外安装 Node.js、npm 或 pnpm。
- 安装结束时会自动写入 DSH 插件。若自动写入失败，可手动添加插件路径：
  - dsh plugin --profile web add file:%LOCALAPPDATA%\Programs\beautiCode\integrations\deepseek-harness
  - npx @deepseek-ai/dsh plugin --profile web add file:%LOCALAPPDATA%\Programs\beautiCode\integrations\deepseek-harness
- 当前安装包尚未进行商业代码签名，Windows 可能显示 SmartScreen 提示。
- 用户导入的图片、视频和已保存主题位于 %LOCALAPPDATA%\beautiCode，卸载程序默认保留这些数据。

## 从源码运行
适合开发者或希望完全控制集成流程的用户。

前置条件
- Node.js 22 或更高版本
- 项目根目录

操作步骤
1. 安装依赖：
   - npm install
2. 一键写入 DSH 插件：
   - powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-dsh-plugin.ps1
3. 运行 DeepSeek Harness：
   - npx @deepseek-ai/dsh web
4. 如需托盘（用于 Codex 或摸鱼热键）：
   - npm run tray

其他可选方式
- 手动把本地插件目录加进 DSH（需要 pnpm）：
  - npx @deepseek-ai/dsh plugin --profile web add file:%CD%/integrations/deepseek-harness
  - npx @deepseek-ai/dsh web
- 打开宿主选择器：
  - powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-beauticode.ps1
- 构建 Windows 安装包：
  - npm run installer:windows
  - 输出位于 artifacts\windows\installer\

## 配置 DeepSeek Harness 插件（手动添加路径）
当自动写入失败或你希望手动管理插件路径时，可以使用以下方法。

方法一：通过 DSH 命令添加本地插件
- dsh plugin --profile web add file:<你的插件目录>
- 或 npx @deepseek-ai/dsh plugin --profile web add file:<你的插件目录>
- 然后运行 npx @deepseek-ai/dsh web

方法二：使用仓库内脚本写入
- 在项目根目录执行：
  - powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-dsh-plugin.ps1
- 该脚本会尝试将 beautiCode 的 Cordis 插件链接到你的 DSH web profile，并在首次 dsh web 时加载插件。

方法三：Windows 安装包手动修复
- 如果自动写入失败，替换为你的实际安装目录：
  - dsh plugin --profile web add file:%LOCALAPPDATA%\Programs\beautiCode\integrations\deepseek-harness
  - npx @deepseek-ai/dsh plugin --profile web add file:%LOCALAPPDATA%\Programs\beautiCode\integrations\deepseek-harness

注意
- 手动接入时，请确保 DSH 和 beautiCode 使用相同的 BEAUTICODE_DATA_ROOT。
- 插件注册了对话工具和斜杠命令，不需要托盘；若托盘已在运行则复用。
- beautiCode 不启动 DeepSeek Harness，请先自己运行 dsh web。

## Codex Desktop 托盘应用启动指南
托盘用于 Codex Desktop 场景，以及摸鱼热键等功能。

启动方式
- 从源码运行托盘：
  - npm run tray
- 或直接执行 PowerShell 脚本：
  - powershell -NoProfile -ExecutionPolicy Bypass -File apps/tray/start-tray.ps1

托盘功能概览
- 状态显示：运行中/忙碌 + 当前媒体类型（含摸鱼模式）
- 应用或重新应用：确保 ChatGPT/Codex 以回环 CDP 运行，并导入存储的默认背景
- 更换图片/视频：通过系统对话框选择
- 清除背景：同时退出摸鱼模式
- 摸鱼模式：隐藏宿主内容 chrome，媒体全屏并以原生亮度显示；快捷键 Ctrl+Shift+Space
- 视频声音：独立于摸鱼模式，默认静音
- 保存/切换/删除主题：视频主题会记录播放位置
- 退出：离开摸鱼模式、停止会话主机、注销热键、移除托盘图标

安全与行为要点
- 控制面板通过 loopback localhost HTTP 控制通道通信，端口随机，每次启动不同
- 变更操作需要 Authorization: Bearer <token>
- 不会绑定非 127.0.0.1 地址，也不会以 0.0.0.0 调试 Codex
- 日志路径：%LOCALAPPDATA%\beautiCode\logs\tray.log

## 基本背景设置操作
完成安装与插件配置后，你可以快速设置第一个背景。

在 DeepSeek Harness 网页中
- 打开侧栏“背景”
- 选择图片（JPG、JPEG、PNG、WebP）或视频（MP4）
- 立即应用并进入已保存主题
- 可清除背景、开关声音、切换主题

在托盘应用中（适用于 Codex Desktop）
- 点击“更换图片…”或“更换视频…”
- 点击“清除背景”
- 点击“视频声音”开关
- 点击“保存当前主题”或“切换已保存主题”

提示
- 浅色/深色外观跟随宿主（DSH 或 Codex）的设置
- 下次启动会恢复上次背景

## 常见初始配置问题与解决方案
- 无法找到 Node.js 或版本过低
  - 现象：CLI 报错需要 Node.js 22 或更高版本
  - 解决：升级 Node.js 至 22 或更新版本
  - 参考：[package.json:23-25](file://package.json#L23-L25)、[scripts/beauticode.mjs:14-17](file://scripts/beauticode.mjs#L14-L17)

- 一键安装后网页没有“背景”
  - 现象：侧栏未出现背景入口
  - 解决：确认已运行 dsh web；如未生效，重新执行 npx beauticode-dsh；或手动添加插件路径
  - 参考：[README.md:41-66](file://README.md#L41-L66)、[integrations/deepseek-harness/README.zh-CN.md:25-46](file://integrations/deepseek-harness/README.zh-CN.md#L25-L46)

- Windows 安装包自动写入插件失败
  - 现象：安装后无法加载插件
  - 解决：手动添加插件路径到 DSH profile
  - 参考：[README.md:85-90](file://README.md#L85-L90)

- 托盘启动失败
  - 现象：托盘无法启动或崩溃
  - 解决：查看日志 %LOCALAPPDATA%\beautiCode\logs\tray.log；检查是否已有托盘实例占用；重启托盘
  - 参考：[apps/tray/start-tray.ps1:16-31](file://apps/tray/start-tray.ps1#L16-L31)

- SmartScreen 警告
  - 现象：Windows 提示未知发布者
  - 说明：当前安装包未进行商业代码签名，属于预期情况
  - 参考：[docs/windows-installer.md:56-59](file://docs/windows-installer.md#L56-L59)

- 数据与主题丢失
  - 现象：重装或卸载后背景与主题消失
  - 说明：用户数据位于 %LOCALAPPDATA%\beautiCode，卸载程序默认保留
  - 参考：[docs/windows-installer.md:19-24](file://docs/windows-installer.md#L19-L24)

## 结论
按照本指南，你可以在最短时间内成功运行 beautiCode 并设置第一个背景：
- 仅给 DeepSeek Harness 加背景：使用 npx beauticode-dsh
- 需要托盘与自动化：下载 Windows 安装包并运行 dsh web
- 开发者：从源码运行并使用 install-dsh-plugin.ps1 写入插件
- 遇到常见问题时，优先检查 Node.js 版本、插件路径、托盘日志与 SmartScreen 提示
