# ADR 0009：Codex 壁纸外壳与 guest 生命周期

- 日期：2026-10-24
- 状态：接受；现场与自动化证据的范围分别列于验收记录。
- 基线：main aea3220；来源 PR #96 head d5f3252。
- 关联：[实施与验收记录](../pr96-owner-completion.md)、PR #96。

## 问题与现场事实

PR 把原生圆角、tooltip、功能浮层、内容路由和 guest 注入混在两个文件中。
固定浅色背景与宿主深色文字体系冲突；同代次短路前创建观察器会泄漏。
尺寸扫描不能辨认页面外壳和阅读底板，直接修改内联背景还必须保存声明优先级。

26.1016.6573.0 的宿主静态资源声明 /plugins、/library、/sites、/images 原生路由。
实际切页也确认这些入口在宿主文档呈现；不能据路由声明推断所有版本均无 webview。
当前存在独立的定价预热 webview：src 是 about:blank，toUrl 是相对路径，实际地址为 chatgpt.com。
因此排除 sandbox 或仅限制 chatgpt.com 都不能形成正确的页面边界。
支付与工作区设置资源还包含独立 webview 流程，本适配不进入这些流程。

站点页的外壳由 workspace slot、全高 bg-surface、contents、滚动容器及居中 tabpanel 构成。
资料库复用滚动标题结构，但不具有站点页的全高 bg-surface 根节点。
两者的标题底板是滚动内容标题壳的 ::before；清理 h1 本身无效。
真实 DOM 中存在生成类名，但它们只作为调查证据，不作为本次适配选择器。

## 决策

### 宿主样式

只删除 beautiCode 对左栏、main 和首页卡片圆角的清零，保留宿主实际圆角。
当前宿主部分外层原生圆角为 0；本修复不承诺把这些外层改成指定像素。
普通 tooltip 保留原生底色与前景；Radix 定位壳透明，真正菜单面板保留主题底色。
浮层及 sidebar peek 使用 --bc-readable-fill；peek 仅裁切并修正直接底板，沿用宿主圆角。
所有新浮层规则排除 beautiCode 自身 UI 及其后代。

保留 ADR 0008 的空、非交互 composer 装饰层规则。
原生页面只匹配观测到的 workspace/滚动/标题/tabpanel 结构。
不清空所有 bg-surface，不使用视口大小推断语义，也不新增生成类名兜底。
布局契约失效时保持宿主底板，而不是回退到更宽泛的透明规则。

### 模块与所有权

媒体入口只负责代次、组合、舞台及销毁；工作态、用户播放偏好、媒体来源、图片、
视频节点、就绪/重试和既有 API 分别拥有状态。
图片与视频附件均需要可取消的原生事件等待，因此复用小型 media-wait 模块。
销毁会取消等待并解绑事件；旧图片完成后不能更新下一代根属性。
公开七个注入参数、既有方法名及健康快照字段保持不变。
修正偏好恢复调用：沿用已有 isBackgroundTone 方法，不新增兼容别名。
模块通过操作、只读 getter 和回调协作，不共享可变状态包。

payload 在注入表达式的词法作用域内组合工厂，避免浏览器端 ESM/CSP 或新增全局注册框架。
主入口从约 2022 行降到不足 400 行，新增媒体与 guest 模块均小于 500 行。
保留现有 renderer 资产复制和插件打包机制，不引入运行时依赖。

### guest 契约与生命周期

guest 控制器内部接口为 setActive(boolean)、sync()、dispose()。
同一文档同版本复用；媒体交接不捕获旧代次闭包，完整销毁释放实例。
未激活时不创建宿主观察器，也不绑定 guest 事件或注入 CSS。

条件允许的内容根路由仅 /plugins、/library、/sites、/images。
还要求宿主 main 中的已连接 webview、about:blank 的预期路径和当前 HTTPS
chatgpt.com 精确路径一致；不接受端口、用户凭据、相似域名或任意子路径。
prewarm、sandbox、定价/结算/工作区 partition 及所有未知路由均拒绝。
/pricing-plan、/checkout、/admin、认证流程和未验证的 /plans 不在允许表中。
查询参数不作为账号授权依据，不将它们写入日志。

“候选页面”只允许绑定就绪事件，只有实际地址通过校验才可注入。
dom-ready、主框架导航、页内导航与动态挂载均重新检查。
不支持或尚未验证的版本保持原生；没有合适现场实例时不得宣称 guest 现场验收通过。

用 Electron insertCSS/removeInsertedCSS 的键管理根外壳样式。
guest 自身表单、卡片、弹层及主题变量不改写；不安装 guest DOM 观察器、不改内联背景。
样式只涉及 html/body 及直接根节点，内层没有已验证契约时不扩展清理范围。
宿主视图使用宿主 CSS 处理其原生内层外壳。

每个登记实例只有一个未完成插入调用；操作版本随导航、清除和销毁递增。
过期结果通过自己的样式键撤销，不能删除重新激活后的新样式。
旧调用阻塞过新文档时，完成后只为变化过的版本补同步一次；拒绝/超时不无限重试。
超时为 3000ms。Electron Promise 不能真正取消；超时保留原生显示并诊断，
迟到的成功结果仍会回收，底层 Promise 永不完成时不再堆积新调用。
清理依赖登记表，能够处理已脱离 DOM 的 webview。
撤销 API 拒绝时给出阶段/类别诊断，不能把 API 失败宣称为成功恢复。

## 验证与限制

Node 测试覆盖边界、候选就绪、动态新增/移除、100 次实例复用、清理竞态、超时、
错误脱敏、视频交接后永久错误和图片取消。
真实 Edge 浏览器执行完整载荷，覆盖主题切换、圆角、保留阅读卡片、媒体和交接；
最终 Codex 插件包内载荷重复执行同组关键回归。
合成浏览器中的 webview API 替身不是 Electron 现场证明。
真实客户端检查仅临时替换 CSS，检查原生内容页后恢复；不安装新运行时或修改媒体档案。
详细通过数、截图、采样视频及未验收边界见实施记录。

## 演进与回滚

宿主变更后先更新脱敏 DOM 样例和对应回归，再调整结构或允许表。
新增 guest 页面必须有真实 URL、身份及根外壳证据，不扩大域名或尺寸扫描兜底。
现有日志不会包含正文、账号或完整 URL。
本次不改存储键及档案协议；回滚本组提交并重新打包即可恢复旧运行时。
若已经安装某个包，应先停止该包的辅助注入进程，再切换到上一包，避免两代注入竞争；
不修改 Codex 二进制，也无需数据迁移。
